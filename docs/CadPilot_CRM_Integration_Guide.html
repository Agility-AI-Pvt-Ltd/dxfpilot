Integration spec · for the CRM developer

Connecting the CRM to CadPilot

A CRM record sends its two Excel workbooks to CadPilot. The CRM user opens CadPilot from a link, checks the options and generates the P&ID. Once a reviewer approves it, the DXF drawing comes back to the CRM, where users can preview and download it.

Auth shared API key, server to server Return channel signed webhook and/or polling Files 2 × .xlsx in, 1 × .dxf out (+ SVG preview)

01How it works

Four steps. The CRM builds steps 1, 2 and 4. Step 3 happens entirely inside CadPilot.

SendThe user fills the P&ID form on a CRM record: name plus the two workbooks. The CRM backend POSTs them to CadPilot and stores the launch_url it gets back.
OpenThe user clicks Open in CadPilot, a plain link to launch_url. CadPilot shows its New P&ID draft page with the name and both files already filled in.
Draft & approveIn CadPilot the user picks the plant sections and engine, generates the P&ID, corrects it in chat and approves it.
ReceiveCadPilot POSTs the approved DXF to the CRM webhook. The CRM stores it and shows a preview and a Download DXF button on the record.
sequenceDiagram
  autonumber
  actor U as CRM user
  participant CU as CRM UI (browser)
  participant CB as CRM backend
  participant CP as CadPilot (EC2)
  U->>CU: Fill P&ID form, attach 2 × .xlsx
  CU->>CB: POST /api/records/{id}/pid (multipart)
  CB->>CP: POST /api/integrations/crm/projects (X-API-Key)
  CP-->>CB: project_id, launch_url, state=draft_pending
  CB-->>CU: saved request + launch_url
  U->>CP: Click "Open in CadPilot" (launch_url, new tab)
  Note over U,CP: Choose options → Generate → review → Approve
  CP->>CB: POST /webhooks/cadpilot (signed JSON with DXF)
  CB-->>CP: 200 OK
  U->>CU: Back on the record
  CU->>CB: GET /api/records/{id}/pid
  CB-->>CU: state=approved, preview + download

The API key never reaches the browser. The CRM UI only talks to the CRM backend, and the CRM backend talks to CadPilot. The only CadPilot URLs the browser sees are launch_url and, optionally, the signed preview and download links.

03Network & firewall

The CRM and CadPilot run on different EC2 instances. Three connections must work.

From → ToUsed forAllow
CRM backend → CadPilotSend workbooks, status, DXF downloadCadPilot security group: inbound 80/443 from the CRM EC2's IP
User's browser → CadPilotOpening launch_url, signed preview/download linksCadPilot security group: inbound 80/443 from users (office/VPN range)
CadPilot → CRM backendApproval webhookCRM security group: inbound on the webhook port from CadPilot EC2's public IP. Skip this if you use polling only.

Use HTTPS in production on both sides. The API key, the workbooks and the drawings otherwise travel in plain text. CadPilot switches to HTTPS automatically when it is given a domain (SITE_ADDRESS).

Check from the CRM EC2: curl http://<cadpilot>/api/health should return {"ok":true,…}.

What the backend does

  1. Check that the user may edit recordId, and that both files are .xlsx and together under 25 MB.
  2. Call CadPilot POST /api/integrations/crm/projects (section 06) with external_id = recordId, callback_url = CRM_PUBLIC_URL + "/webhooks/cadpilot" and return_url = CRM_PUBLIC_URL + "/records/" + recordId.
  3. Upsert the pid_requests row (section 05) with project_id, launch_url and state.
  4. Return the row to the UI.

Response to the UI

  "state": "draft_pending",
  "launch_url": "http://13.233.10.20/?p=8f453f24f363&from=crm",
  "files": { "mass_balance": "Mass_Balance.xlsx", "design_data": "Design_Data.xlsx" },

Pass CadPilot's error text through for 400s (for example "Could not read the workbook: …"). Map 401/503 from CadPilot to 502 "CadPilot integration misconfigured", because the user cannot fix those.

GET/api/records/:recordId/pid/dxf

Linked from the Download DXF button

Serve the stored DXF with Content-Type: application/dxf and Content-Disposition: attachment; filename="<dxf_filename>". If there is no stored copy (for example, the webhook was missed), fetch it from CadPilot GET /api/integrations/crm/projects/{recordId}/dxf, store it, then serve it. Return 409 while nothing is approved.

GET/api/records/:recordId/pid/preview.svg

Used as <img src> on the record page

Fetch the stored svg_url (from the webhook or status) and stream it back as image/svg+xml. Proxying keeps the CRM page on its own origin and applies CRM permissions. Alternatively, put svg_url straight into <img>: it is signed and works without the key, but anyone holding the URL can open it.

POST/webhooks/cadpilot

Called by CadPilot when a revision is approved · public route, no CRM login, authenticated by signature

  1. Read the raw body; don't parse JSON first. Limit it to 30 MB.
  2. Verify the signature and timestamp (section 07). If either fails, return 401.
  3. Decode dxf.content_base64 and store the file (S3, disk or DB) under external_id + revision.
  4. Update the row: state=approved, approved revision, svg_url, dxf_url, received_via=webhook.
  5. Return 200 within ~10 s. Do slow work (notifications, emails) afterwards.

Must be idempotent. CadPilot retries failures and a reviewer can press Send again, so the same external_id + revision can arrive twice. Overwrite; don't duplicate.

POST/api/records/:recordId/pid/redeliver optional

Admin / support button

Proxies CadPilot POST /api/integrations/crm/projects/{recordId}/redeliver. Useful after the CRM webhook was down.

A whole-plant DXF is about 0.2–0.6 MB (base64 adds a third), so allow request bodies up to 30 MB.

Verifying the signature

  1. signed = timestamp + "." + rawBody (the exact bytes received)
  2. expected = "sha256=" + hex(HMAC_SHA256(CADPILOT_WEBHOOK_SECRET, signed))
  3. Compare it with X-CadPilot-Signature using a constant-time comparison.
  4. Reject if |now − timestamp| > 300 seconds (replay protection).

Retries

CadPilot counts any 2xx as delivered. Anything else, or a timeout (30 s), is retried 3 times in total, 2 s and 4 s apart. After that the reviewer sees "Delivery failed · Send again" in CadPilot, and you can call redeliver. As a safety net, the CRM's status refresh also pulls the DXF when state is approved but no file is stored.

09Reference code

A complete working CRM backend in Node 18+ (Express + multer). Adapt the storage and permission checks to your stack.

crm-backend/cadpilot.jsJavaScript
// npm i express multer
const express = require("express");
const multer = require("multer");
const crypto = require("crypto");
const fs = require("fs/promises");
const path = require("path");

const CADPILOT_URL = process.env.CADPILOT_URL.replace(/\/$/, "");
const API_KEY = process.env.CADPILOT_CRM_API_KEY;
const SECRET = process.env.CADPILOT_WEBHOOK_SECRET;
const CRM_PUBLIC_URL = process.env.CRM_PUBLIC_URL.replace(/\/$/, "");
const USE_WEBHOOK = process.env.CADPILOT_USE_WEBHOOK !== "false";
const DXF_DIR = process.env.DXF_DIR || "./dxf-store";

const upload = multer({ storage: multer.memoryStorage(), limits: { fileSize: 25 * 1024 * 1024 } });
const router = express.Router();

// ---- replace with your database ------------------------------------------------------------
const db = new Map(); // record_id -> row (see "CRM data model")
const getRow = async (id) => db.get(id) || null;
const saveRow = async (row) => { db.set(row.record_id, { ...row, updated_at: new Date().toISOString() }); return db.get(row.record_id); };

function cadpilot(p, init = {}) {
  return fetch(CADPILOT_URL + p, {
    ...init,
    headers: { "X-API-Key": API_KEY, ...(init.headers || {}) },
    signal: AbortSignal.timeout(120_000),
  });
}

function view(row) {
  if (!row) return { state: "none" };
  return {
    record_id: row.record_id, project_id: row.project_id, state: row.state, launch_url: row.launch_url,
    files: { mass_balance: row.mass_balance_name, design_data: row.design_data_name },
    current_revision: row.current_revision || null,
    approved: row.approved_revision ? {
      revision: row.approved_revision, approved_by: row.approved_by, approved_at: row.approved_at,
      dxf_filename: row.dxf_filename, received_via: row.received_via,
    } : null,
    stale: !!row.stale,
  };
}

// ---- 1. Send the workbooks ---------------------------------------------------------------------
router.post("/api/records/:id/pid",
  upload.fields([{ name: "mass_balance", maxCount: 1 }, { name: "design_data", maxCount: 1 }]),
  async (req, res) => {
    const id = req.params.id; // TODO: check the logged-in user may edit this record
    const files = req.files || {};
    for (const role of ["mass_balance", "design_data"]) {
      const f = files[role]?.[0];
      if (f && !f.originalname.toLowerCase().endsWith(".xlsx")) return res.status(400).json({ error: `${f.originalname}: only .xlsx is supported` });
    }
    const form = new FormData();
    form.set("external_id", id);
    form.set("name", req.body.name || "");
    form.set("request", req.body.request || "");
    form.set("return_url", `${CRM_PUBLIC_URL}/records/${encodeURIComponent(id)}`);
    if (USE_WEBHOOK) form.set("callback_url", `${CRM_PUBLIC_URL}/webhooks/cadpilot`);
    for (const role of ["mass_balance", "design_data"]) {
      const f = files[role]?.[0];
      if (f) form.set(role, new Blob([f.buffer]), f.originalname);
    }
    const r = await cadpilot("/api/integrations/crm/projects", { method: "POST", body: form });
    const out = await r.json().catch(() => ({}));
    if (r.status === 400) return res.status(400).json({ error: out.detail });
    if (!r.ok) return res.status(502).json({ error: "CadPilot integration misconfigured (" + r.status + ")" });

    const prev = (await getRow(id)) || { record_id: id, created_at: new Date().toISOString() };
    const row = await saveRow({
      ...prev,
      project_id: out.project_id, launch_url: out.launch_url, state: out.state,
      mass_balance_name: out.sources.mass_balance, design_data_name: out.sources.design_data,
      current_revision: out.current_revision,
    });
    res.json(view(row));
  });

// ---- 2. Status (refreshes from CadPilot) -------------------------------------------------------
router.get("/api/records/:id/pid", async (req, res) => {
  const row = await getRow(req.params.id);
  if (!row) return res.json(view(null));
  try {
    const r = await cadpilot(`/api/integrations/crm/projects/${encodeURIComponent(row.record_id)}`);
    if (!r.ok) throw new Error("status " + r.status);
    const s = await r.json();
    const ap = s.approved_revision;
    Object.assign(row, { state: s.state, current_revision: s.current_revision, launch_url: s.launch_url, stale: false });
    if (ap && ap.revision !== row.approved_revision) {
      // approved but the webhook hasn't delivered this revision (yet): pull it
      Object.assign(row, { approved_revision: ap.revision, approved_by: ap.approved_by, approved_at: ap.approved_at,
                           dxf_url: ap.dxf_url, svg_url: ap.svg_url, dxf_storage_key: null });
      await pullDxf(row);
    }
    res.json(view(await saveRow(row)));
  } catch {
    res.json(view({ ...row, stale: true }));
  }
});

async function pullDxf(row) {
  const r = await cadpilot(`/api/integrations/crm/projects/${encodeURIComponent(row.record_id)}/dxf`);
  if (!r.ok) return;
  const name = /filename="([^"]+)"/.exec(r.headers.get("content-disposition") || "")?.[1] || `${row.record_id}.dxf`;
  await storeDxf(row, name, Buffer.from(await r.arrayBuffer()), "pull");
}

async function storeDxf(row, filename, buf, via) {
  await fs.mkdir(DXF_DIR, { recursive: true });
  const key = `${row.record_id.replace(/[^\w.-]/g, "_")}_rev${row.approved_revision}.dxf`;
  await fs.writeFile(path.join(DXF_DIR, key), buf); // or upload to S3
  Object.assign(row, { dxf_filename: filename, dxf_storage_key: key, dxf_size: buf.length, received_via: via });
}

// ---- 3. Download --------------------------------------------------------------------------------
router.get("/api/records/:id/pid/dxf", async (req, res) => {
  const row = await getRow(req.params.id);
  if (!row?.approved_revision) return res.status(409).json({ error: "Not approved yet" });
  if (!row.dxf_storage_key) { await pullDxf(row); await saveRow(row); }
  if (!row.dxf_storage_key) return res.status(502).json({ error: "Could not fetch the DXF from CadPilot" });
  res.set("Content-Type", "application/dxf");
  res.set("Content-Disposition", `attachment; filename="${row.dxf_filename}"`);
  res.send(await fs.readFile(path.join(DXF_DIR, row.dxf_storage_key)));
});

// ---- 4. Preview ---------------------------------------------------------------------------------
router.get("/api/records/:id/pid/preview.svg", async (req, res) => {
  const row = await getRow(req.params.id);
  if (!row?.svg_url) return res.status(404).end();
  const r = await fetch(row.svg_url, { signal: AbortSignal.timeout(60_000) });
  if (!r.ok) return res.status(502).end();
  res.set("Content-Type", "image/svg+xml").set("Cache-Control", "private, max-age=300");
  res.send(Buffer.from(await r.arrayBuffer()));
});

// ---- 5. Webhook (mount BEFORE any global express.json()) ----------------------------------------
router.post("/webhooks/cadpilot", express.raw({ type: "application/json", limit: "30mb" }), async (req, res) => {
  const ts = req.get("X-CadPilot-Timestamp") || "";
  const got = req.get("X-CadPilot-Signature") || "";
  const expected = "sha256=" + crypto.createHmac("sha256", SECRET).update(ts + ".").update(req.body).digest("hex");
  const fresh = Math.abs(Date.now() / 1000 - Number(ts)) <= 300;
  if (!fresh || got.length !== expected.length || !crypto.timingSafeEqual(Buffer.from(got), Buffer.from(expected)))
    return res.sendStatus(401);

  const msg = JSON.parse(req.body.toString("utf8"));
  if (msg.event !== "drawing.approved") return res.sendStatus(200);
  const row = (await getRow(msg.external_id)) || { record_id: msg.external_id, created_at: new Date().toISOString() };
  Object.assign(row, {
    project_id: msg.project_id, launch_url: msg.launch_url, state: "approved",
    approved_revision: msg.revision, approved_by: msg.approved_by, approved_at: msg.approved_at,
    dxf_url: msg.dxf.url, svg_url: msg.svg_url,
  });
  await storeDxf(row, msg.dxf.filename, Buffer.from(msg.dxf.content_base64, "base64"), "webhook"); // same rev twice = overwrite
  await saveRow(row);
  res.sendStatus(200);
});

// ---- 6. Optional: resend ------------------------------------------------------------------------
router.post("/api/records/:id/pid/redeliver", async (req, res) => {
  const r = await cadpilot(`/api/integrations/crm/projects/${encodeURIComponent(req.params.id)}/redeliver`, { method: "POST" });
  res.status(r.status).json(await r.json().catch(() => ({})));
});

10What the CRM user sees in CadPilot

None of this needs CRM code. It is here so the CRM team can explain it to users.

  1. New P&ID draft page (first visit): the project name and both workbooks are pre-filled, marked "received from the CRM". The user can rename the project, replace a workbook and edit the instruction.
  2. They choose Plant sections: Detect from the workbooks (recommended) or Choose the sections myself. They also choose the Draft engine: Rules (recommended) or LLM planner.
  3. Generate draft. Nothing is generated before this click.
  4. The workspace shows a banner: "From CRM record LEAD-1001 · When you approve, the DXF is sent to the CRM automatically", plus ← Back to CRM (return_url).
  5. They correct the drawing in chat (each correction makes a new revision A, B, C…) and click Approve. The banner then shows "Revision B DXF delivered to the CRM", or "Delivery failed · Send again".
  6. Opening launch_url again later goes straight to the workspace.

11Acceptance checklist

Run these against the real CadPilot EC2 before go-live.

  • From the CRM EC2, curl $CADPILOT_URL/api/health returns "ok":true.
  • Sending a record with both workbooks returns created: true, state: draft_pending, and a launch_url that starts with the public CadPilot address (not localhost).
  • Sending the same record again returns the same project_id with created: false.
  • A .xls/.csv file is rejected in the UI and by the backend. A corrupt .xlsx shows CadPilot's 400 message.
  • A wrong API key gives the user a clear "integration misconfigured" error, not a stack trace.
  • Open in CadPilot shows the pre-filled New P&ID draft page, and nothing is generated until Generate draft is clicked.
  • After approval, the CRM receives the webhook (check the logs), the signature is valid, and the DXF is stored.
  • The record shows Approved · rev X, the preview renders, and Download DXF saves a file that opens in AutoCAD / DWG TrueView.
  • A webhook with a changed body or an old timestamp is rejected with 401.
  • With the webhook blocked (or CADPILOT_USE_WEBHOOK=false), Refresh status still ends in Approved and the DXF downloads (pull path).
  • Approving a second revision in CadPilot updates the CRM to the new revision; the same revision delivered twice doesn't create duplicates.
  • ← Back to CRM in CadPilot lands on the right record.
